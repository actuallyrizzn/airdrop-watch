# Changelog

## [0.1.1] - 2026-09-08

### Fixed
- Token USD pricing falls back to **DexScreener** when the explorer returns a null `exchange_rate` (typical for fresh airdrops).

## [0.1.0] - 2026-09-08

### Added
- Initial public extract of **Airdrop Watch**: PHP dashboard (auth, live poll, tabbed airdrop panel with pause-new), config-driven chain JSON, optional FlareSolverr snapshot proxy.
- Documentation: architecture, deployment, configuration, chains; dual license AGPL-3.0 (code) + CC-BY-SA-4.0 (docs).
- Roadmap note: more chain support planned.
